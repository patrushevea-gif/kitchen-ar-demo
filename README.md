# Kitchen AR Demo

Каркас демо-проекта для фабрики кухни РМ. Старый проект `furniture` не используется и не изменяется.

## Что внутри

- Vite + React.
- Three.js-превью модульной кухни.
- Конфигуратор длины стены, схемы, модулей и материалов.
- UI в стилистике сайта кухни РМ: контактная полоса, каталог, карточки преимуществ, красный акцент, светлый фон.
- Заготовка под AR-сценарий и форму заявки.

## Запуск

```bash
npm install
npm run dev
```

## Следующие шаги

1. Выбрать конкретную кухню с сайта клиента для пилота.
2. Подготовить 3D-модули в GLB/USDZ.
3. Подключить экспорт собранной сцены в AR.
4. Подключить отправку заявки в почту, Telegram или CRM.
