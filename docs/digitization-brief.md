# Digitization Brief

Пилот делается бесплатно на одной кухне, поэтому объем намеренно ограничен. Цель: показать механику продаж, а не построить полный CAD-конструктор.

## Пилотная кухня

- Название: Графит Кварц черный Турин.
- Источник: https://kitchenrm.ru/grafit-kvarts-chernyy-turin/
- Основной размер с сайта: 2200x2400 мм.
- Цена на карточке: от 93 000 руб.
- Фасады: Графит фреза + Кварц черный фреза.
- Столешница: Дуб Вотан 26 мм.
- Стекло: Графит софт.
- Профиль: Gola черный.

## Требования к GLB

- Единицы: 1 unit = 1 meter.
- Origin: низ модуля по центру.
- Материал-слоты: `front`, `body`, `countertop`, `handle`, `glass`.
- Геометрия легкая, без внутренних деталей, которые не видны в AR.
- Названия объектов стабильные: `base_600`, `sink_800`, `wall_glass_800`.

## Завтрашний MVP

1. Заменить процедурные Three.js-блоки на первые GLB-заглушки модулей.
2. Проверить смену 3 материалов без замены геометрии.
3. Подготовить цельный GLB для режима AR готовой кухни.
4. Оставить движение отдельных модулей только в веб-конструкторе.
